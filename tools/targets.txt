# Build manifest for tools/build.sh
#
# One target per line, fields separated by "|":
#   scad path (relative to repo root) | output basename | outputs | defines | camera
#
#   outputs  comma list of: stl, 3mf, png
#            stl/3mf go to build/ (git-ignored; published as release assets),
#            png goes to <scad dir>/images/ (committed, used by the READMEs)
#   defines  semicolon-separated OpenSCAD variable overrides, e.g.
#            part="grip";print_orient=false     (may be empty)
#   camera   OpenSCAD --camera value for PNGs, "tx,ty,tz,rx,ry,rz,dist"
#            (may be empty = default view; the view is auto-centred)
#   mode     optional, PNGs only: "render" (default, exact geometry) or
#            "preview" (keeps colours, e.g. stand-in controllers)
#
# Lines starting with # are ignored.
