# Assets

`voltage_wordmark.svg` is the VOLTAGE wordmark, a trademark of Voltage
Solutions LLC. It is **not** covered by the repository's CC BY-SA 4.0 license.

The designs load it with OpenSCAD's `import()`, so it has to stay here for the
logo to render from source. To make your own version without it, set
`logo = false` in the Customizer, or point `logo_file` at your own SVG
(filled shapes only).
